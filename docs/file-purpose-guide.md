# AI Career Companion File Purpose Guide

This document explains the purpose of the maintained files in the repository. Generated dependencies and build output are described separately at the end.

## Project Root

| File | Purpose |
| --- | --- |
| `README.md` | Project overview, current frontend status, scope, and commands for running the application. |
| `package.json` | Defines the project name, npm scripts, runtime dependencies, and development dependencies. |
| `package-lock.json` | Locks the exact npm dependency versions so installs are repeatable. Do not edit manually. |
| `index.html` | Vite's browser entry document. It sets the page title, viewport, theme color, root element, and loads `src/main.tsx`. |
| `vite.config.ts` | Configures Vite and enables the React plugin used for development and production builds. |
| `eslint.config.js` | Defines ESLint rules for TypeScript, React Hooks, React Fast Refresh, browser globals, and ignored build output. |
| `tsconfig.json` | Root TypeScript configuration that references the application and Node/Vite configurations. |
| `tsconfig.app.json` | TypeScript settings for React application code under `src/`, including strict checking and JSX support. |
| `tsconfig.node.json` | TypeScript settings for Node-side configuration files such as `vite.config.ts`. |
| `.gitignore` | Prevents dependencies, build output, secrets, local data, logs, and editor files from being committed. |

## Frontend Source

| File | Purpose |
| --- | --- |
| `src/main.tsx` | React bootstrap entry. It mounts `App` into the HTML root and enables `StrictMode`. |
| `src/App.tsx` | Main application composition. It contains the shared shell, navigation, route/view selection, authentication demo, page components, forms, CTA actions, and local UI state. |
| `src/App.css` | Main visual system. It defines the existing dark-green sidebar, cream workspace, typography, cards, buttons, forms, dashboard layouts, responsive breakpoints, roadmap, assistant, progress, and authentication styling. |
| `src/index.css` | Global CSS reset and base browser styles, including the project font stack, box sizing, body defaults, and visible focus rules. |
| `src/mockData.ts` | Centralized replaceable demo data for careers, skill comparisons, learning roadmap items, resume analysis, and recent activity. |
| `src/services/careerService.ts` | Service abstraction for career data and assistant responses. It currently exports `mockCareerService`; a real API service can later implement the same interface. |
| `src/vite-env.d.ts` | Provides Vite and `import.meta` type declarations to TypeScript. |
| `src/assets/react.svg` | Starter asset generated by Vite. It is currently not part of the product UI and can be removed when asset cleanup is performed. |

## Frontend Responsibilities

### `App.tsx`

The application currently uses a lightweight view router based on `window.location.pathname`. It supports the planned frontend paths for:

- dashboard
- profile
- resume analyzer
- resume results
- career recommendations
- career details
- skill gap analysis
- learning roadmap
- AI career assistant
- progress tracker
- settings
- login, signup, and onboarding entry screens

The file also owns temporary frontend state such as the selected career, uploaded resume state, roadmap completion state, and demo session authentication.

### `mockData.ts`

This is the preferred place to change demo content. Components should not contain scattered fake career scores, skills, roadmap items, or resume-analysis values. Replace this module with API response mapping when the backend becomes available.

### `careerService.ts`

This separates UI components from data access. The current service returns local mock data and a deterministic assistant response. It does not call an external AI provider, backend, or database.

## Generated or Local Files

| File or directory | Purpose |
| --- | --- |
| `node_modules/` | Installed npm packages. Generated by `npm install`; never edit or commit it. |
| `dist/` | Production build output generated by `npm run build`; never edit manually. |
| `node_modules/.tmp/` | TypeScript incremental build information generated during type checking. |
| `*.log` | Local diagnostic or tool logs. These are ignored by Git. |
| `.env` and `.env.*` | Local environment configuration. These are ignored to protect secrets. No backend environment variables are currently required by the frontend. |

## Current Integration Boundary

The frontend is currently mock-backed. It is not connected to FastAPI, PostgreSQL, authentication, resume storage, resume parsing, an LLM provider, or the planned AI agents. The service abstraction and centralized mock data are the intended replacement points for those integrations.
