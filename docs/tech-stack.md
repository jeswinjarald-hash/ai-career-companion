The technologies below are the initial proposal for the project. These are proposed technologies, not final implementation decisions.

| Layer               | Proposed Technology                   |
| ------------------- | ------------------------------------- |
| Frontend            | React + Vite                          |
| Frontend Language   | TypeScript                            |
| Backend             | Python + FastAPI                      |
| Database            | PostgreSQL                            |
| ORM                 | SQLAlchemy                            |
| LLM                 | OpenAI API                            |
| Agent Orchestration | LangGraph                             |
| Vector Search       | pgvector                              |
| RAG                 | To be finalized based on requirements |
| Resume Processing   | Python-based document/PDF processing  |
| API Documentation   | OpenAPI / Swagger                     |
| Version Control     | Git + GitHub                          |
| Containerization    | Docker                                |
| Development         | VS Code                               |

These are proposed technologies only. Do not install or configure technologies that are not currently being implemented.
