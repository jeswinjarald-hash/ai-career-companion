# AI Career Companion

## Overview

AI Career Companion is an agentic AI platform intended to help students navigate internship applications and career preparation through profile understanding, resume analysis, and future AI-assisted guidance.

## Current Development Status

Status: Project foundation / Milestone 1

## Current Milestone

Milestone 1 focuses on:

- Research and technical understanding
- System architecture
- Student profile
- Resume upload
- Resume parsing
- Structured candidate extraction

## Planned System Components

Planned / evolving architecture:

- Student/User Interface
- Backend/API Layer
- Database
- LLM
- Resume Upload/Storage
- Resume Parsing Module
- Candidate Profile
- Job-Posting Knowledge Base
- RAG Pipeline
- AI Agent Layer
- Application Tracking Module

## Planned Agents

Agent implementation has not started yet. The current planned agents are:

- Job-Resume Matching Agent
- Skill Gap Agent
- Resume Agent
- Cover Letter Agent
- Interview Agent
- Career Assistant

## Development Philosophy

- Build incrementally.
- Implement one module at a time.
- Do not implement future milestones prematurely.
- Keep architecture modular.
- Prefer simple solutions over unnecessary complexity.
- Keep the architecture adaptable as requirements evolve.
- Every major feature should be testable.
- Do not introduce technologies without a concrete project requirement.
